## 2026-09-28 — Gate 3: жизненный цикл пользователя в каждом боте

**Почему.** Бан сети и статус «пользователь остановил этого бота» — разные факты. Рассылка и досье не должны их смешивать.

**Что сделано.** Таблица `user_bot_statuses`: `active` / `stopped` / `deleted`, отсутствие ряда — `unknown`. Процесс запоминает origin после фактического `bot.id`. Блокировка в личке ставит `stopped`, возврат — `active`. Обычное личное событие подтверждает `active`; первый такой запуск один раз пишет событие в events-тему. `user is deactivated` помечает `deleted` у известных ботов этой SQLite-сети. Временная ошибка статус не меняет. Рассылка берёт `active` и ещё неизвестных, затем фиксирует достоверную ошибку. Досье показывает санкцию сети и таблицу ботов. Канон polling включает `my_chat_member`; узкий список без него даёт предупреждение.

**Проверка.** `pytest tests -q`: **145 passed**. Tag `profiling` не двигался.

**Не тронуто.** Gate 4 и дальше, поиск по username, `bot_gateway.py`, соседние репозитории, push.
