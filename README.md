> **Универсальное переносимое шасси для Telegram-ботов нового поколения на `aiogram v3`.**  
> Единый UX, бронебойная рантайм-защита, неисчезающие кнопки, двусторонняя поддержка и встроенная маркетинговая воронка.

---

## 🚗 Почему именно «Шасси» (Chassis)?

В классической автоинженерии **шасси** — это готовая несущая платформа: рама, двигатель, трансмиссия, подвеска, рулевое управление и тормоза.
На одно и то же шасси автоконцерн может установить:
- кузов седана (`Profiling Bot` — психолингвистический анализ текста),
- кузов внедорожника (`PsyBot` — клиническая психологическая диагностика),
- кузов фургона (`Chat Listener` — мониторинг чатов и лидогенерация).

При этом водителю гарантированы одинаково высокий уровень пассивной безопасности, отзывчивость руля и предсказуемость тормозов.

**Bot Chassis** решает ту же задачу для Telegram-ботов: вся сложная «ходовая часть» (жизненный цикл экранов, анти-дребезг кликов, транспорт поддержки, платежи, права и меню) написана, протестирована и заморожена в виде автономного пакета.

## 🌟 Ключевые возможности

### 1. Каноническая триада нижнего меню
Вместо перегруженных клавиатур из 5–7 кнопок в шасси закреплена выверенная нижняя триада:
```text
┌────────────────────────┬───────────────────┬────────────────────────┐
│   👤 Личный кабинет    │      ℹ️ Info      │      💬 Поддержка      │
└────────────────────────┴───────────────────┴────────────────────────┘
```
- Клавиатура зафиксирована через Telegram API: `is_persistent=True`, `resize_keyboard=True`.
- Сохраняет плейсхолдер в строке ввода (`input_field_placeholder="Выберите действие в меню"`).

### 2. Синяя кнопка «[Меню]» Telegram (`bot.set_my_commands()`)
- **Страховка от потери интерфейса:** Пользователи часто случайно смахивают или скрывают нижнюю клавиатуру (иконка с четырьмя точками справа от поля ввода). 
- Синяя кнопка меню зашита в нативный клиент Telegram и **не может исчезнуть никогда**.
- Клик по ней открывает список команд: `/start`, `/menu`, `/cabinet`, `/info`, `/support`.
- Команда `/menu` мгновенно переотправляет пользователю актуальный экран с кнопками, если он потерялся.

### 3. Личный кабинет (Кабинет пользователя)
- **Платёжный контур:** баланс Telegram Stars, тарифная сетка, статус подписки (активна / истекает / лимит бесплатных разборов).
- **Умное ранжирование истории:** сверху выводятся сессии и анализы с наивысшим баллом выраженности (`severity_score`), требующие внимания пользователя; ниже — хронологический архив.
- **Мгновенное скачивание:** кнопка `[📥 Скачать отчёт]` отдает готовый файл прямо из Telegram (`telegram_file_id`) без повторного расчета.
- **Профиль:** ID пользователя, дата первого старта, реферальная программа.

### 4. Интерактивный хаб Info + Взаимная воронка кросс-промо
- **О проекте:** прозрачное объяснение методологии человеческим языком.
- **«Хейт-трек»:** доказательный разбор слепых зон устаревших методов и неэффективных детекторов.
- **FAQ:** пошаговое руководство (как выгрузить чат за 3 клика, как читать шкалы и радары).
- 🚀 **Кросс-промо воронка (`[Другие проекты]`):** каждый бот экосистемы льет трафик в соседние продукты сети (витрина ботов с описаниями и UTM-ссылками).
- **Комьюнити:** прямая ссылка на открытую группу взаимопомощи / чат поддержки.
- **152-ФЗ и медицинский дисклеймер:** юридическая прозрачность и безопасность.
- **Мультиязычность (`🌐 English`):** мгновенное переключение языка интерфейса без перезапуска бота.

### 5. Поддержка: Chat Listener Bridge + LLM-оператор + Отзывы
- **Двусторонний мост поддержки:** пользователь пишет текст, записывает голосовое или присылает скриншот прямо в диалог с ботом. Сообщение улетает в закрытый чат команды. Администратор нажимает **Reply** — и бот доставляет ответ в личку пользователю.
- **Архитектура LLM-оператора:** готовность к подключению AI-саппорта 1-й линии для автоответов по базе FAQ с прозрачной эскалацией на живого человека.
- **Донаты (`⭐ Поддержать проект`):** поддержка через Telegram Stars.
- **Модуль отзывов (`[✍️ Оставить отзыв]` / `[⭐ Читать отзывы]`):** формирование социального доверия (Social Proof).

### 6. Бронебойная UX-защита
- **RAM-only сессии ввода (`InMemoryPendingInputStore`):** 0 байт на жестком диске. Микро-словарик в памяти (~50 байт на пользователя). Автоматический сброс ожидания ввода при нажатии на любую кнопку главного меню.
- **Плавный UI (`edit_or_send`):** экраны редактируются на месте. Ошибка Telegram `message is not modified` перехватывается и гасится.
- **Автозакрытие старых экранов (`close_previous_user_screen`):** бот снимает кнопки со старых экранов при переходе в новые разделы, предотвращая появление «кладбища кнопок».
- **Дедупликация кликов (`ActiveTaskTracker`):** защита от быстрого спама по кнопкам и автоматическая отмена (`task.cancel()`) устаревших задач при смене вкладки.
- **3-секундный флеш-экран:** стильная анимация преимуществ при `/start`.

## 📂 Структура проекта

```text
bot_chassis/
├── src/
│   └── bot_chassis/
│       ├── __init__.py           # Публичный API пакета
│       ├── contracts.py          # Константы, лейблы кнопок, префиксы callback_data
│       ├── keyboards.py          # Фабрика Reply и Inline клавиатур
│       ├── followup.py           # InMemoryPendingInputStore (RAM-only сброс ввода)
│       ├── lifecycle.py          # edit_or_send, close_previous_user_screen
│       ├── dispatcher.py         # ActiveTaskTracker (дедупликация и отмена задач)
│       ├── commands.py           # bot.set_my_commands и startup-оповещения
│       ├── support_bridge.py     # Двусторонний Chat Listener мост
│       └── router.py             # aiogram v3 Router, связывающий всё воедино
├── examples/
│   ├── run_example.py            # Готовый пример запуска бота
│   └── .env.example              # Шаблон переменных окружения
├── tests/
│   └── test_chassis.py           # Полный сьют юнит-тестов (100% green)
├── docs/
│   └── UNIVERSAL_BOT_CHASSIS_SPEC.md # Полная архитектурная спецификация
├── pyproject.toml                # Конфигурация сборки и pytest
├── requirements.txt              # Зависимости
└── README.md
```

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```
или для разработки в режиме editable:
```bash
pip install -e .
```

### 2. Запуск тестов
```bash
pytest -v
```

### 3. Запуск примера бота
Создайте файл `.env` в корне (или задайте переменные окружения):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
SUPPORT_CHAT_ID=-1001234567890
ADMIN_IDS=108234567
```

Запустите пример:
```bash
python examples/run_example.py
```

## 🧩 Подключение в существующий проект на aiogram v3

```python
from aiogram import Bot, Dispatcher
from bot_chassis import (
    create_bot_chassis_router,
    setup_bot_commands,
    notify_admins_on_startup,
)

bot = Bot(token="YOUR_TELEGRAM_BOT_TOKEN")
dp = Dispatcher()

# 1. Регистрируем синюю системную кнопку [Меню]
await setup_bot_commands(bot)

# 2. Подключаем роутер шасси
chassis_router = create_bot_chassis_router(
    support_chat_id=-1001234567890,
    project_name="Мой Новый Проект",
    support_project_label="Саппорт Моего Бота",
)
dp.include_router(chassis_router)

# 3. Добавляем ваши специфические доменные роутеры (тесты, парсеры, файлы)
# dp.include_router(my_domain_router)
```
